How to handle lyrics:
Lyrics can be either .txt or .lrc files, with the text you want to show when someone runs the lyric command for the currently playing file.
Lyrics aren't supported for files playing from web links.
Lyrics must be placed with folder structure **EXACTLY** matching where the files are in /Assets/Music. If this isn't the case, the command _will not_ find the files.
Lyrics aren't time-synced, and .lrc files will have all time indicators stripped if present, while .txt files will be displayed as-is.
